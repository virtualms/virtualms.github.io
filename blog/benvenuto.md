# Aloha!

Questo è il mio nuovo **Blog / Portfolio** realizzato interamente in puro HTML, CSS e JavaScript, seguendo il paradigma stilistico del *Neo Brutalism*.

## Perché questa scelta?

- **Zero dipendenze:** Nessun framework complesso o build step.
- **Velocità:** Tutto il rendering viene eseguito localmente sul browser.
- **Personalità:** Un design forte, ispirato alle origini del web ma con un tocco di modernità.

### Come funziona la sezione blog?
Scrivo un articolo in Markdown (esattamente come questo), lo metto nella cartella `blog/`, eseguo uno script in locale e l'articolo diventa istantaneamente disponibile e leggibile sulla pagina!
